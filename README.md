# omoran-portafolio
Mi portafolio personal

## Páginas privadas

- `videos-para-ver/` está protegida con **Cloudflare Access** (Zero Trust › Aplicaciones › "Videos para ver (privado)").
  Solo entran los correos de la política "Solo Oscar", con un código de un solo uso enviado por correo.
  Cubre `oscarmorantrejo.com`, `omoran-portafolio.pages.dev` y sus vistas previas `*.omoran-portafolio.pages.dev`.
  Además tiene `noindex` y está bloqueada en `robots.txt`.
- Para dar acceso a alguien más, agregar su correo en esa política; no hace falta tocar el código.
